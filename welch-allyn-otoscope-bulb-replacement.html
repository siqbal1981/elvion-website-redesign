Welch Allyn otoscope bulb replacement: find the lamp reference by model

Bulbs are sold by lamp reference, not by instrument model. This page matches Welch Allyn otoscope model numbers to the lamp reference Welch Allyn's own chart lists for them.

If you search for a Welch Allyn otoscope light bulb replacement, you usually start from the number on your instrument, such as 20000 or 25020. The bulb itself is identified by a lamp reference, such as 03100-U or 03400-U. Welch Allyn's own lamp replacement chart connects the two. The table below repeats the otoscope entries from that chart for the lamp references ELVION sells.

Head number or handle number?

Many Welch Allyn sets use one handle with several heads, and each head can take a different lamp. The lamp is usually chosen by the head, so note the numbers printed on both the head and the handle. If you are not sure which number to use, see how to find your lamp reference.

If your otoscope model is not listed

The table covers only the lamp references ELVION sells. A model that is not listed may use a different reference, and that does not mean a bulb for it is unavailable. Check your manual, or send us your instrument model and we will tell you whether we can confirm a matching ELVION bulb. We do not guess.

Before you order

  3. Open the ELVION page for that reference and use its Buy button to see the exact Amazon listing.

Frequently asked questions

Which lamp reference does Welch Allyn list for the 25020 otoscope?

Welch Allyn's lamp replacement chart lists lamp reference 03100-U for otoscope 25020. Confirm it in your own manual before you order.

Which lamp reference does Welch Allyn list for the 21110 otoscope?

Welch Allyn's lamp replacement chart lists lamp reference 03400-U for otoscope 21110. Confirm it in your own manual before you order.

Which lamp reference does Welch Allyn list for the Macroview 23820 otoscope?

Welch Allyn's lamp replacement chart lists the 06500-U family for Macroview otoscope 23820. ELVION sells this lamp under the name HPX06500, which does not appear in the chart, so ask us to check before you buy.

Is the 03100-U bulb the same as the 03400-U bulb?

No. They are separate lamp references that the chart lists for different instruments. Bulbs that look alike are not always interchangeable, so match the reference in your manual.

My otoscope model is not in the table. What should I do?

The table only covers the references ELVION sells. A model that is not listed may use a different lamp reference. Check your manual or the full Welch Allyn chart, or send us the model printed on your instrument and we will tell you whether we can confirm a matching ELVION bulb.
